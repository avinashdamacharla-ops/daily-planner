# 🌟 Daylight — Daily Planner

A modern, responsive daily planner web application designed to help you organize your day, manage tasks, and stay productive.

## 🚀 Features

- ➕ Add new daily tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🏷️ Categorize tasks into Study, Work, Health, and Personal
- ⏰ Set task times
- 📊 Track daily progress and completion percentage
- 🎯 25-minute focus timer
- 📝 Quick notes with automatic saving
- 💾 Automatically saves tasks and notes in your browser
- 📱 Responsive design for desktop and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## ▶️ How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The Daily Planner will open in your browser.

## 🚀 Deploy Using GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch.
6. Select `/ (root)` as the folder.
7. Click **Save**.

Your website will be published using GitHub Pages.
